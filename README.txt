# Operación Extracción

Juego web de disparos en primera persona contra zombis desarrollado con
**Three.js**. El objetivo es recorrer las calles urbanas, recolectar
munición y llegar con vida a la zona de extracción.

Cómo ejecutar el proyecto:
1 Abre el proyecto en VS Code.
2 Instala la extensión Live Server (de Ritwick Dey).
3 En el explorador de archivos de VS Code, dale clic derecho a index.html.
4 Selecciona Open with Live Server.
